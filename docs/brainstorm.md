# Brainstorm mode (coming soon)
*Created: 2026-10-31. Last updated: 2026-10-31.*

Brainstorm mode is not built yet. This page says what it is for. The repo has no example of it and no engine code behind it.

## Two ways to start

Today a user builds an agent with Quick start. They say what agent they want and add what it needs to know. For a sales agent, that can be the brand identity file.

Brainstorm will sit beside Quick start, and the user picks one:

- Quick start: say what you want and add what the agent needs to know.
- Brainstorm: talk the idea through with the AI, the way a founder thinks out loud with a partner, until both agree on the agent plan. The plan says what the agent does, for whom, its goals and its limits.

In Brainstorm, ideas are not tested one by one. The talk goes on until the plan is agreed, and then the build starts.

Either way, the agent starts in the Arena with zero lessons. Every lesson it has is earned there. A brainstorm shapes the plan, never the lessons.

## What a brainstorm feeds

Every brainstorm leaves two kinds of data: the conversation itself, and its results. The results are what the agent built from it did in the Arena and with real customers. One case id links the two. The conversations teach the brainstorm partner, and the results teach the rest of Unfenced:

1. A better brainstorm partner. Past brainstorms whose agents did well teach it to ask better questions and reach a strong plan sooner with the next user.
2. Better starting plans. It shows which plans (goals, limits) led to agents that went live fastest. This shapes the plan, not the lessons.
3. What to build next. What users keep asking for shows which agents and industries to add, and the trust level each industry needs.
4. Customer cards for new industries. Users describe their customers' worries. Once real chats back that up, it can seed customer cards for an industry with little data.
5. A living map of the market. Across many users, cleaned and anonymous, it shows what businesses need.

## Privacy

- Every brainstorm is cleaned before the engine reads it.
- A user's own words never leave their account.
- Only patterns seen across many users are used.
- A user can choose to have their brainstorms kept for only 30 days.
- The full rules will be in the Unfenced privacy policy before launch.
